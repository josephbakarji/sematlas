# SemAtlas Vision & Philosophy

## Core Purpose
Create a platform where **learning = doing + absorbing** - a space for navigating knowledge through interactive feedback loops.

## Key Principles

### 1. Knowledge Navigation
- Visualize knowledge as an interactive 3D graph
- Allow selection, synthesis, and testing of knowledge
- Enable LLM-assisted management and manipulation

### 2. Interactive Learning
- Learning through writing and interaction, not just consumption
- Positive feedback loops between exploration and creation
- Dynamic synthesis of ideas across documents

### 3. Future Vision: Society of Specialized LLMs

**Core Hypothesis:** Ensemble of specialized LLMs > One generalist LLM

**Architecture:**
- Multiple LLM "agents" with distinct personalities and specializations
- Each agent trained/exposed to different subsamples of data
- Agents can be: Mathematician, Critic, Holistic Thinker, Technical Analyst, etc.
- Parallel processing across agents
- Synthesis through agent interaction and ensembling

**Benefits:**
- Parallelization of learning and processing
- Diverse, well-rounded perspectives
- Robustness through specialization
- Natural regularization via ensemble

**Research Questions:**
1. Do sub-LLMs trained on data subsamples perform better when ensembled vs. one large LLM?
2. Can specialized agents develop emergent collaborative intelligence?
3. Does agent interaction improve synthesis quality?

### 4. User Workflow (Ideal State)
```
User Input (writing, audio, ideas)
    ↓
Extract Topics & Visualize
    ↓
Connect to Prior Knowledge
    ↓
Recommend Related Content
    ↓
User Explores & Learns
    ↓
User Creates (writes, synthesizes)
    ↓
System Assists (specialized agents)
    ↓
Loop: Continuous feedback
```

### 5. Character-Based Interaction
- Specialized characters: Mathematician, Philosopher, Engineer, Artist
- Each character focused on specific aspects of data
- User can converse with specific characters or let them discuss
- Characters can critique, extend, or synthesize ideas

## Target Audience

**Primary:**
- **Students** - Curiosity-driven exploration
- **Researchers** - Deep analysis and synthesis

**Needs:**
- Bookmarking and saving explorations
- Fast, responsive visualizations
- Ability to trace learning paths
- Synthesis and insight generation

## Technical Priorities (Near-Term)

1. **Speed** - Fast graph generation and rendering
2. **Depth** - Rich semantic extraction and relationships
3. **Visualization** - Clear, interactive, informative graphs
4. **Bookmarking** - Save and revisit knowledge graphs

## Monetization (Future)
- Free tier (core features)
- Premium tier (advanced synthesis, unlimited saves, API access)
- Focus on value delivery first, monetization later

## Technology Choices
- **AI Model:** GPT-3.5 or GPT-4o-mini (balance of cost/quality)
- **Storage:** Session-only initially, migrate to user accounts
- **Data Privacy:** Local-first when possible, user owns their data

## Future Features

### Short-term
- Wikipedia link recursion (fixed)
- Fast graph generation
- Basic bookmarking

### Medium-term
- User accounts and persistent graphs
- Ensemble LLM synthesis
- Specialized agent conversations
- Writing assistant integration

### Long-term
- Full "society of LLMs" implementation
- Cross-document synthesis
- Temporal visualization (idea evolution)
- Multi-modal support (audio, video, PDFs)
- Local LLM integration
- Project-specific knowledge graphs (engineering, music, writing)

## Research Directions

1. **Ensemble LLM Architecture**
   - Sub-sample data across agents
   - Measure synthesis quality vs. monolithic model
   - Study emergent collaborative behaviors

2. **Knowledge Graph Intelligence**
   - Automatic concept extraction
   - Relationship inference
   - Missing link suggestion

3. **Interactive Learning Systems**
   - Feedback loop optimization
   - Learning path recommendation
   - Synthesis quality metrics

---

**Philosophy:** Intelligence is fundamentally social and collaborative. The future of AGI is not one super-intelligent agent, but a society of specialized agents working together - just like humans.

**Mission:** Build tools that empower humans to be in the loop, guiding the search through combinatorial possibility spaces, while AI handles the execution.
